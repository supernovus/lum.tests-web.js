# lum.tests-web-jsdom.js

A plugin for [@lumjs/tests-web] that adds [global-jsdom]
as a supported global DOM implementation for testing with.

## Exports

|          Exported module          |        Description        |
| --------------------------------- | ------------------------- |
| `@lumjs/tests-web-jsdom`          | Exports the plugin class. |
| `@lumjs/tests-web-jsdom/register` | Registers the plugin.     |

## Official URLs

This library can be found in two places:

 * [Github](https://github.com/supernovus/lum.tests-web.js/tree/main/packages/jsdom)
 * [NPM](https://www.npmjs.com/package/@lumjs/tests-web-jsdom)
