# lum.tests-web-happy.js

A plugin for [@lumjs/tests-web] that adds [@happy-dom/global-registrator]
as a supported global DOM implementation for testing with.

## Exports

|          Exported module          |        Description        |
| --------------------------------- | ------------------------- |
| `@lumjs/tests-web-happy`          | Exports the plugin class. |
| `@lumjs/tests-web-happy/register` | Registers the plugin.     |

## Official URLs

This library can be found in two places:

 * [Github](https://github.com/supernovus/lum.tests-web.js/tree/main/packages/happy)
